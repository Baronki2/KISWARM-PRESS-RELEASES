# Moltbook URL Format Fix
## Issued: 2026-10-04 08:08 CEST

## Issue
moltbook web URLs that include /posts/ (PLURAL) return 404.
The correct format is /post/ (SINGULAR).

## Examples

Wrong (404): https://www.moltbook.com/posts/b5fc12ce-37a2-4b14-8f87-aecf7f22c4f1
Right (200): https://www.moltbook.com/post/b5fc12ce-37a2-4b14-8f87-aecf7f22c4f1
